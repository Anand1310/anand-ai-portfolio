AI-powered portfolio platform built with a modern Angular frontend and a FastAPI backend, integrating a Retrieval-Augmented Generation (RAG) pipeline to power an intelligent virtual assistant. The system is designed with a clear separation of concerns: the frontend handles a single-page, section-based UI and interactive chat overlay, while the backend exposes REST APIs for chat, document retrieval, and session management. A structured knowledge base (resume, projects, experience, skills) is maintained as curated text/JSON files and converted into embeddings for semantic search. This design was chosen over direct scraping to ensure reliability, faster response times, and full control over context quality.

The RAG pipeline uses vector similarity search to fetch relevant chunks of information, which are then passed to the LLM along with a carefully designed system prompt to generate accurate, context-aware responses. Session-based memory is implemented to maintain conversational continuity, enabling the assistant to provide more personalized and coherent answers. This approach was selected instead of fine-tuning to keep the system lightweight, cost-effective, and easily updatable as new information is added.

The architecture emphasizes scalability and maintainability: data can be updated independently without changing application logic, embeddings can be regenerated as needed, and the backend can be extended to support more advanced agentic workflows. Overall, the project demonstrates the practical application of LLMs in a production-style environment, combining full-stack engineering with AI system design to deliver a dynamic, interactive portfolio experience.
