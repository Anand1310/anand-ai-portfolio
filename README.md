# 🤖 AI Agent Portfolio

An AI-powered personal portfolio website featuring an intelligent agent that can answer questions about my experience, projects, and skills using RAG and tool-based reasoning.

---

## 🚀 Overview

This project is a production-ready portfolio built with:

- **Frontend:** Angular (Standalone Architecture)
- **Backend:** FastAPI
- **AI System:** Agentic workflow using LangGraph
- **Capabilities:** RAG, memory, tool calling

The highlight of this portfolio is an **AI assistant** that allows recruiters to interactively explore my profile.

---

## ✨ Features

- 🧠 AI-powered chatbot (ask about my experience, skills, projects)
- 🔎 RAG-based retrieval from resume, projects, and knowledge base
- 🔗 Tool-augmented agent (calculator, retrieval, reasoning)
- 💬 Conversational memory support
- ⚡ FastAPI backend for scalable AI serving
- 🎯 Clean, modern Angular UI
